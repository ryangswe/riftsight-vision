The demo needs a model before it can name a card. Give it the address of a release document.

Or choose a release folder on this computer. Its files are read by this page; nothing is uploaded.

Or stop the server and start it with a release folder. The model then loads by itself:

npm run demo -- --release RELEASE-FOLDER
